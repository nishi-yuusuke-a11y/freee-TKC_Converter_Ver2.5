ステップ3: 科目割当

※ＦＸクラウドの勘定科目、補助科目にも下記の設定と同じものを登録してください。

親科目のコードを入力すると補助科目にも自動反映。補助コード入力で以降連番自動入力。

ステップ4: 税区分割当

freeeの税区分（I列・AP列）にTKCの課税区分を設定してください。

📋 課税区分一覧

ステップ5: 取引先割当

取引先コードは6桁数字。入力すると以降に連番が自動入力されます。

📌 取引先別管理をしている科目
※当該科目はＦＸクラウドでも取引先別管理科目としてください。
※補助コードが空白のものは999999：その他取引先として取り込みます。
※同じ背景色 = 同一候補の重複グループ（例: 株式会社ＴＫＣ / ㈱ＴＫＣ / （株）ＴＫＣ / (株)ＴＫＣ / 株式会社TKC / ㈱TKC / （株）TKC / (株)TKC / 株）ＴＫＣ / 株）TKC / 株)ＴＫＣ / 株)TKC など）

ステップ6: 部門割当

freeeの部門名（U列・BB列）にTKC部門コードを割り当ててください。初期値は共通部門（000）です。

ステップ7: 確認＆仕訳作成（FXC連動シート形式）

未割当の項目があります。未割当は空欄として出力されます。

プレビュー（先頭20件・主要列）

※ オレンジ背景 = 未割当（空欄出力）。部門コードは科目4000番台以上のみ出力。複数ファイル取込時はファイルごとに個別出力されます。仕訳の期間が4か月を超える場合は、最初の月から4か月ごとに区切って出力されます。

作成したファイルを開き、秘密度ラベルを解除してからＦＸクラウドに取り込んでください。
